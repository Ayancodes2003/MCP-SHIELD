# Security policy

mcp-shield is alpha software and a security control: treat it as one layer, not a guarantee (see the limitations in the
README and [docs/threat-model.md](docs/threat-model.md)).

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the maintainers (use the repository's private security advisory
feature once the repository is published) and do not open a public issue. Include the version, configuration (without
secrets), and a reproduction. Detector evasions are expected in a heuristic system and are welcome as normal issues with
a sample payload; policy bypasses, authentication bypasses, audit-chain forgeries and credential leaks are
vulnerabilities.

## Supported versions

Only the latest 0.x release receives fixes.
